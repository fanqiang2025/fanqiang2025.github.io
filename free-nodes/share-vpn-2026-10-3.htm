iso小火箭（俗称"小火箭"）是基于V2ray核心技术的科学上网工具，它不仅仅是一个简单的代理软件，更是一个功能全面的网络自由解决方案。在信息封锁日益严重的今天，这款工具为用户打开了一扇通往广阔互联网世界的大门。

1.1 核心功能解析

小火箭V2ray之所以受到广泛欢迎，主要得益于其强大的功能组合： - 突破封锁：轻松访问被屏蔽的各类网站和服务，包括社交媒体、新闻网站等 - 隐私保护：采用先进的加密技术，确保用户上网行为不被监控和记录 - 协议多样：支持VMess、Shadowsocks等多种代理协议，适应不同网络环境 - 跨平台兼容：可在iOS、Android、Windows等多个平台上运行，满足不同设备需求 - 配置灵活：提供丰富的自定义选项，让高级用户能够根据需求进行精细调整

节点优化技巧： - 定期测试节点延迟和速度 - 根据使用时段选择不同节点 - 建立节点分组（如按地区、用途分类）

通过路由规则可以精细控制哪些流量走代理： 1. 全局代理：所有流量通过小火箭 2. 规则代理：根据域名/IP决定是否代理 3. 直连模式：仅特定流量走代理

建议配置： - 国内网站直连 - 国际服务走代理 - 敏感域名强制代理

FAQ

PassWall2 如何实现智能分流？
PassWall2 通过自定义规则文件控制流量走向。可根据目标域名、国家或 IP 范围自动判断走代理或直连。用户还能加载社区规则，实现类似 Clash 的高效路由分流。
Shadowrocket 的重写功能有什么用途？
Shadowrocket 的重写功能允许用户在请求阶段修改 HTTP 头、响应内容或重定向 URL。这一功能常用于屏蔽广告、解锁区域限制或调试网页请求，非常灵活强大。
PassWall2 如何实现按域名分流？
PassWall2 可通过域名规则匹配请求，将流量分流至指定节点。结合策略组和自动测速，可让不同网站走不同节点，实现加速和优化访问速度的效果。
Clash 节点延迟检测如何帮助分流？
Clash 会定期测试节点延迟，并结合策略组自动选择最优节点处理流量。避免访问高延迟或失效节点，提高网页浏览、视频播放和游戏速度及稳定性，优化整体网络体验。
WinXray 的节点延迟过高怎么办？
可通过策略组切换低延迟节点，或调整传输协议和端口。检查服务器网络和防火墙设置，确保网络通畅。必要时可启用 MUX 功能减少短连接延迟，提高整体网络体验。
V2Ray 的流量分流规则支持哪些条件？
V2Ray 支持按域名、IP、端口、协议或用户标签进行分流。用户可灵活设置国内直连、国外代理或特定节点，实现精准控制和网络优化。
Trojan 协议支持 UDP 吗？
支持。Trojan 在最新版本中已支持 UDP 转发，能够满足游戏、视频会议等实时性需求较高的应用场景，性能和兼容性都有明显提升。
Mellow TUN 模式如何拦截全局流量？
TUN 模式会拦截系统 IP 层的所有流量，实现全局代理。相比 SOCKS5 只影响部分应用，TUN 可以覆盖游戏、视频和浏览器等所有流量，提高科学上网体验的全面性。
Mellow TUN 模式对系统全局流量的作用是什么？
TUN 模式拦截系统 IP 层的所有流量，实现全局代理效果。相比 SOCKS5 只作用于特定应用，TUN 能覆盖游戏、视频和浏览器流量，保证全系统科学上网体验稳定高效。
V2RayN 的作用是什么？
V2RayN 是 V2Ray 的 Windows 图形客户端，提供节点管理、订阅导入、日志查看等功能。它支持多协议配置，并可与系统代理集成，是 Windows 用户最常用的代理管理工具之一。
